= Bilateral and Comparative Assessment -- ANF Worked Examples

indexterm:[ANF, bilateral assessment example]
indexterm:[relative measurement, worked example]
This reference provides worked examples of building ANF
statements from clinical narratives that involve comparative
and relative measurements.
Each example demonstrates the use of comparative unit concepts
with intrinsic `measurementBasis` properties as described in
xref:anf-relative-measurements[] and defined in
xref:anf-measurement-basis-units[].
The examples follow the same tabular format used in the
xref:anf-example-blood-pressure[blood pressure] and
xref:anf-example-medication[medication history] worked examples.

== Example 1: PERRLA -- Pupils Equal (Qualitative)

indexterm:[PERRLA, qualitative assessment]
indexterm:[bilateral symmetry assessment, pupil example]

[example]
====
*Neurological Examination* +
Clinical narrative:
"PERRLA" +
Element isolated:
"Pupils equal" (assessed without measurement)
====

This statement captures the bilateral symmetry assessment
performed by visual inspection.
No absolute pupil diameter is recorded;
the result is a qualitative comparison.

.Performance Circumstance -- Pupil Bilateral Symmetry (Qualitative)
[cols="2,3", options="header"]

NOTE: The reference frame (contralateral anatomical structure) is carried by the unit definition, not repeated in the statement.
Any statement using "Bilateral symmetry assessment" as its semantic inherits the comparative reference frame automatically.
